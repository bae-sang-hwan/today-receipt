하루 OX 캘린더 화면설계서

하루에 한 번, O 아니면 X만 남기는 초간단 기록 캘린더입니다. 운동, 금주, 약 먹기처럼 "했다/안 했다"만 기록하면 되는 일을 홈 화면 위젯에서 탭 한 번으로 끝내는 것이 목표입니다.

앱 이름 하루 OX 캘린더 플랫폼 Android 전용 문서 버전 v1.0 구현 반영 작성일 2026-10-06 브랜치 feature/haru-ox-calendar
개요

만들 때 지킬 원칙

탭 한 번이면 끝

날짜를 누를 때마다 빈칸 → O → X → 빈칸으로 바뀝니다. 확인 창, 저장 버튼은 없습니다.

위젯에서 끝낸다

앱을 열지 않고 홈 화면 위젯에서 바로 오늘을 체크합니다. 이 앱의 차별점입니다.

로그인은 선택

설치하자마자 로그인 없이 씁니다. 원하는 사람만 설정에서 Google로 로그인해 자동 백업합니다.

기능을 늘리지 않는다

할 일, 일정, 시간 기록은 넣지 않습니다. "가장 단순한 앱"이 정체성입니다.

목적

    최대 12자, 필수.

백업 및 동기화

목적
원하는 사람만 Google 로그인으로 기록을 자동 백업하고, 기기를 바꿔도 이어서 씁니다.
로그인 전
설명 한 줄과 [Google로 백업 시작] 버튼만 보입니다. 기존 앱의 Firebase 로그인을 그대로 씁니다.
  1. 계정

    로그인한 Google 계정의 이메일.

  2. 동기화 상태

    마지막 동기화 시각. 실패하면 "인터넷 연결을 확인해 주세요"로 바뀝니다. [지금 동기화]로 바로 다시 시도합니다.

  3. 안내

    기록이 어디에 저장되는지 한 줄로 설명합니다.

  4. 로그아웃

    기기의 기록은 남기고 동기화만 멈춥니다.

  5. 계정 삭제

    서버의 기록과 계정을 지웁니다. 화면 안에서 한 번 더 확인받고, 기기의 기록은 남깁니다. Google Play 정책상 필수이며, 웹에서 삭제를 요청할 수 있는 페이지도 따로 만들어야 합니다.

처음 로그인할 때: 기기 기록을 서버로 올립니다. 서버에 이미 기록이 있으면(재설치, 기기 변경) 둘을 합치고, 같은 날짜가 겹치면 나중에 수정한 값을 남깁니다.

위젯 설정

위젯을 놓을 때 뜨는 화면. 연결할 캘린더와 테마(밝게/어둡게)를 고릅니다. 어둡게는 프리미엄 전용이라 무료 사용자에게는 흐리게 보이고, 누르면 경고 진동만 옵니다. 앱에 캘린더가 없으면 "먼저 앱에서 캘린더를 만들어 주세요"를 보여줍니다. 위젯을 길게 눌러 다시 바꿀 수 있습니다.

위젯과 앱은 항상 같은 값을 보여야 합니다. 위젯에서 바꾸면 앱이 다음에 열릴 때 반영되고, 앱에서 바꾸면 위젯을 즉시 갱신합니다. 위젯은 30분마다, 그리고 앱을 열 때마다 다시 그려서 자정이 지나면 "오늘"이 다음 날로 넘어갑니다. "오늘 한 칸"은 누른 순간의 날짜로 기록하므로, 자정 직후 위젯이 아직 어제를 보여줘도 오늘에 기록됩니다.

공통 정책

규칙 정리

항목규칙
기록 값날짜 하나에 빈칸 / O / X 중 하나. 탭하면 빈칸 → O → X → 빈칸 순서로 바뀝니다.
수정 가능 범위오늘과 지난 날은 언제든 수정 가능. 미래 날짜는 누를 수 없습니다.
달성률O 일수 ÷ 지난 날 수. 이번 달 1일부터 어제까지 세고, 오늘은 기록했을 때만 넣습니다. 기록 시작 전 날짜는 빼고 셉니다.
예: 10월 1~5일 중 O 4번, 오늘 빈칸 → 4 ÷ 5 = 80%
연속 일수오늘부터 거꾸로 O가 이어진 날 수. 오늘이 빈칸이면 어제부터 셉니다(하루가 끝나기 전엔 끊지 않음). X나 빈칸을 만나면 멈춥니다.
알림캘린더별로 켜고 시각을 정합니다(새 캘린더는 오후 9:00 켜짐). 그날 그 캘린더가 빈칸일 때만 보냅니다. 로컬 알림은 울릴 때 조건을 확인할 수 없어서, 앞으로 30일치를 날짜별로 예약하되 이미 기록한 날은 빼고, 기록이 바뀔 때마다 다시 예약합니다. 30일 동안 앱을 열지 않으면 알림이 멈춥니다. 알림을 누르면 해당 캘린더의 S02가 열립니다.
광고무료 사용자에게 하단 배너만. 탭할 때 전면 광고는 넣지 않습니다(사용감을 크게 해침).
무료 한도캘린더 2개, 위젯 밝은 테마. 3번째 캘린더를 추가하려 하면 S08이 열립니다.
햅틱모든 버튼은 누를 때 진동이 옵니다. 버튼과 스위치는 가볍게, 날짜 기록은 중간, 길게 누르기는 강하게, 저장·구매 완료는 성공 진동, 삭제 확인과 잠긴 기능은 경고 진동입니다. 위젯을 눌러 기록할 때도 진동합니다.
저장항상 기기에 먼저 저장합니다. 위젯도 기기 저장소에 바로 씁니다. 로그인하지 않으면 서버로 아무것도 보내지 않습니다.
동기화로그인한 경우에만. 기기에서 바뀐 기록을 인터넷이 연결될 때 서버로 올리고, 앱을 열 때 서버 변경분을 받아옵니다. 같은 날짜가 겹치면 updatedAt이 더 늦은 값을 남깁니다. 항상 서버에서 먼저 받아온 뒤 올려서, 오래된 기기 값이 서버의 최신 값을 덮어쓰지 않게 합니다. 위젯에서 한 기록은 다음에 앱을 열 때 올라갑니다.
계정 삭제앱 안(S09)과 웹 페이지 두 곳에서 가능해야 합니다. 삭제하면 서버 기록을 모두 지웁니다.
날짜 기준기기의 현지 날짜(자정 기준). 시간대를 바꿔도 이미 기록한 날짜는 옮기지 않습니다.

코드 밖에서 해야 할 것

  • Play Console에 비소모성 인앱 상품 premium_lifetime을 ₩2,900으로 등록
  • firestore.rules 배포 (users/{uid} 아래 백업 규칙 추가됨)
  • src/ox/config.ts에 문의 이메일, 개인정보처리방침 주소, 웹 계정 삭제 페이지 주소 채우기 (웹 계정 삭제 페이지는 Google Play 정책상 필수)
  • 개인정보처리방침을 하루 OX 캘린더 내용으로 새로 작성 (카메라 권한 삭제, 선택형 Google 로그인과 백업 추가)
  • 새 앱 아이콘과 스플래시 이미지, 위젯 미리보기 이미지
  • 스토어 등록정보 전체 교체: 이름, 설명, 스크린샷, 데이터 보안 양식, 콘텐츠 등급
  • 배포된 Cloud Functions(가족 푸시 알림) 삭제: firebase functions:delete
  • 개발용 앱을 다시 빌드해서 실제 기기에서 위젯, 결제, 로그인, 알림 확인
